# ريل شرح نظيف — الصور ورا الراس

## الستايل (هذا اللي نقلّده بالضبط)

| العنصر | شكله | متى |
|---|---|---|
| **الهوك** | كلمات بيضاء ضخمة (Tajawal Black ~150px) **كلمة بكل سطر**، مكدّسة بعمود جنب المتحدث، ممدودة بالكشيدة لين تصير بنفس العرض (تسـويقك / للحـــين). تطلع كلمة كلمة مع النطق | أول جملة (سؤال غالباً) · لقطة واسعة |
| **الكابشن** | أبيض Bold ~66px، ٢-٣ كلمات، بلا خلفية، ظل ناعم بس، بنص الشاشة على مستوى الصدر (y≈55%) | كل الكلام بعد الهوك |
| **كروت البي-رول** | صورة/سكرين شوت/فيديو بزوايا دائرية وظل خفيف، فوق يسار/يمين/وسط، **ورا الشخص** — راسه وحجابه يغطون جزء منها. تدخل بنطّة صغيرة (scale 0.86→1) | لما يذكر شي له صورة: "التخطيط" → جدول خطة، "التصميم" → شاشة فوتوشوب، "التصوير" → كاميرا |
| **الأكسنت** | سهم نمو بلون البراند ينرسم فوق الكرت (`arrow`) · دائرة تحديد (`circle`) | تقارير، أرقام، نمو، تفصيلة مهمة |
| **اللقطات** | قص حاد بين واسع (zoom 1.0) وقريب (zoom ~1.32) على بداية كلمة | الهوك واسع، وبعده تبديل كل ~٣ ثواني |
| **الإوترو** | خلفية لون البراند، الشعار يلف ويكبر بتوهّج أبيض، يصغر ويطلع اسم البراند بمسح، ثم يطفي | آخر ~٣ ثواني |

**ممنوع:** كروت خلف الكابشن، ألوان على الكابشن، إيموجي، فلاتر على صورة المتحدث. البساطة هي الستايل.

## أسلوبك مع المستخدم
- أنت اللي تجهّز. لا تعطيه أوامر ينفّذها ولا مصطلحات تقنية.
- اطلب شي واحد بكل مرة، وقل له وين وصلنا وكم باقي.
- اعرض عليه ورقة لقطات قبل الرندر الكامل.

## الخطوات

`K` = مجلد هالسكل · `W` = مجلد شغل جديد لكل فيديو.

### 0) التجهيز (بصمت)
```bash
bash $K/scripts/setup.sh || bash $K/scripts/setup.sh --install    # ~600 ميقا أول مرة بس
```
على لينكس لو طلع خطأ `libEGL.so.1`: `apt-get install -y libegl1 libgles2`.

### 1) خذ منه
1. **الفيديو** → `W/src.mp4` (أو src.mov). أفقي أو عمودي، يتقص لـ9:16 تلقائياً.
2. **البراند**: لون أساسي (للسهم والإوترو) + لون تمييز + الشعار PNG شفاف (`W/logo.png`) + اسم البراند للإوترو.
3. **البي-رول**: صور/سكرين شوتات/مقاطع قصيرة → `W/broll/`. ما عنده؟ اقترح عليه وش يصوّر شاشته فيه حسب كلامه. لا تخترع صور منتج ما عندك.

### 2) قص السكتات + التفريغ
```bash
ffmpeg -v error -i $W/src.mp4 -vn -ac 1 -ar 16000 -y $W/a.wav
python3 $K/scripts/vad_cut.py $W          # cut.json — قل له كم ثانية سكوت انشالت
python3 $K/scripts/asr.py $W              # a.raw.json (~٣٠ ثانية لكل ٢٠ ثانية كلام)
```

### 3) صحّح النص ← لا تتخطّاها
افتح `a.raw.json` وصحّح `text` و`words` لكل جملة (وِسبر يغلط بالعامية: «تصبيق»→«تطبيق»، ويقص آخر كلمة أحياناً).
**عدد الكلمات حر** — التوقيت ينحسب بعد التصحيح. **حط علامات الترقيم** (؟ . ،) — كل علامة = حد كرت كابشن، و`؟` بأول جملة تحدد نهاية الهوك.
```bash
python3 $K/scripts/align.py $W            # a.json: كروت ٢-٣ كلمات بتوقيت كل كلمة
python3 $K/scripts/cut.py $W              # cut.mp4 (1080×1920)
python3 $K/scripts/plan_init.py $W        # words.json + مسودة plan.json
```
⚠️ `plan_init.py` يكتب فوق plan.json — بعد ما تعدّله استخدم `--words-only`.

### 4) خطّة المونتاج — `plan.json` (هني شغلك الحقيقي)
```json
{
 "theme": {"brand":"#0B0B6B", "accent":"#E9B85A", "ink":"#FFFFFF",
           "font":"Tajawal-Bold.ttf", "hook_font":"Tajawal-Black.ttf"},
 "hook": {"words":[{"w":"تسويقك","s":0.14},{"w":"للحين","s":0.6}], "e":2.3,
          "side":"left", "kashida":true},
 "captions": [{"s":2.34,"e":3.4,"text":"مثل التخطيط"}],
 "shots": [{"s":0,"e":2.34,"zoom":1.0,"cy":0.3}, {"s":2.34,"e":6.1,"zoom":1.32,"cy":0.3}],
 "broll": [
   {"src":"broll/plan.png","s":2.6,"e":3.4,"pos":"tl","behind":true},
   {"src":"broll/report.png","s":7.1,"e":8.4,"pos":"tc","behind":true,"accent":"arrow"}
 ],
 "outro": {"dur":3.2, "logo":"logo.png", "name":"SparkFlow"}
}
```
- **hook.side**: الجهة الفاضية من الكادر (المتحدث بالنص؟ `left` افتراضي). `top` (0.36) و`width` (0.40) و`size` تتعدل لو ضاق.
- **captions**: من المسودة. ادمج/قسّم بحيث كل كرت ≤ ٣ كلمات ومعنى مكتمل.
- **broll**: التوقيت من `words.json` — الكرت **يبدأ مع الكلمة** اللي تذكره ويختفي قبل الكرت اللي بعده. `pos`: `tl` `tr` `tc` `ml` `mr` أو `[cx,cy]`. `w` عرض نسبي (0.44 افتراضي، `tc` 0.75). كل كرت ٠.٨-١.٥ ثانية. بدّل الجهات (يسار/يمين/وسط) حتى ما يمل.
- **قائمة أشياء** (تخطيط، تصميم، كتابة…) = كرت لكل عنصر بنفس المكان أو جهات متبادلة — هذا قلب الستايل.
- **shots**: الهوك واسع. اللي فيه كروت ورا الراس خله واسع أو قريب خفيف (الكرت يبي مكان فوق الراس). `cy` يرفع/ينزل الكادر، `push: 0.04` زوم بطيء داخل اللقطة.
- **outro**: بلا شعار ولا اسم = بلا إوترو.

### 5) عاين قبل الرندر
```bash
python3 $K/scripts/render.py $W --preview 0.5 1.5 3.0 5.2 7.8 10 13 <TOTAL+1.5>
```
اقرأ `W/sheet.jpg` (ورقة وحدة). تأكد: الهوك ما يغطي الوجه، الكروت ما تطلع من الشاشة، راسه فعلاً قدام الكرت، الكابشن مقروء. اعرضها على المستخدم.

### 6) الرندر + الصوت
```bash
python3 $K/scripts/render.py $W                       # reel.mp4 (~٣× مدة الفيديو)
python3 $K/scripts/render.py $W --range 6 10          # تجربة نافذة بس
bash $K/scripts/master.sh $W                          # reel-master.mp4 بـ‎-14 LUFS
```
ملف صوتي بالخلفية؟ حطه `W/bg-audio.mp3` قبل `master.sh` — ينخفض تلقائياً وقت الكلام (`BG_DB=-20` العلو).

### 7) التحقق والتسليم
- ورقة لقطات من `reel-master.mp4` نفسه (٤-٦ لقطات) — شوفها فعلاً.
- العلو ≈ ‎-14 LUFS (master.sh يطبعه)، الحجم < 30 ميقا.
- سلّم: الملف، المدة، كم انشال سكوت، عدد الكروت. لا تنشر شي.

## قواعد ثابتة
1. **كل نص من كلامه** — لا تضيف جمل ما قالها.
2. **أرقام غربية** (0-9).
3. **صورة المتحدث بألوانها** — لا فلتر ولا تدرّج.
4. الكرت ورا الراس **بس** لما فيه شخص واضح بالكادر؛ لو الخلفية زحمة أو القص طلع خربان بالمعاينة، خله `"behind": false`.
5. الهوك ≤ ٥ كلمات. أطول؟ خله كابشن عادي.
6. أكسنت السهم للنمو/التقارير/الأرقام بس — مو على كل كرت.

## توسيع
أكسنت جديد = دالة `acc_<name>(fr, card, t, alpha)` بـ`render.py` وتضيفها لـ`ACCENTS`. نفس الشي لمكان جديد بـ`POS`.

## خريطة السكربتات
| | يسوي شنو |
|---|---|
| `setup.sh` | يفحص/ينزّل (ffmpeg, mediapipe, sherpa-onnx, whisper-turbo, silero, selfie_segmenter) |
| `vad_cut.py` | يكشف الكلام ويطلّع مقاطع القص → `cut.json` |
| `asr.py` | تفريغ whisper (ONNX) → `a.raw.json` |
| `align.py` | توقيت كل كلمة على منحنى الطاقة + كروت ٢-٣ كلمات → `a.json` |
| `cut.py` | قص + 9:16 → `cut.mp4` |
| `plan_init.py` | `words.json` + مسودة `plan.json` |
| `render.py` | الزوم، قص الشخص، الكروت، الأكسنت، الهوك، الكابشن، الإوترو → `reel.mp4` / `sheet.jpg` |
| `master.sh` | ‎-14 LUFS + خلفية صوتية بخفض تلقائي → `reel-master.mp4` |
