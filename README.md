# الذات والرقم — ريل روحاني 9:16

مونتاج كامل لمقطع «هل هناك ارتباط بين الذات ورقم محدَّد؟» بطابع روحاني / ما وراء علم النفس.
المخرَج ملف عمودي 1080×1920 جاهز للنشر، وكل المونتاج مكتوب كوداً — بلا برنامج مونتاج.

## الهوية البصرية

الألوان مستخرَجة من صورة «3333» المرجعية: نيلي كوني عميق، أبيض نجمي، وذهب دافئ.
كلها بـ`project/theme.json` — وكل الرسم يشتق لونه منها، ما فيه لون ثابت بالكود.

```
bg #070B24 · ink #ECF1FF · acc #F7D68C · clay #C89A46 · mut #8A9CCB
```

`grade: false` — صورة المتحدث تطلع بألوانها الأصلية، بلا أي تدرّج أو صبغة أو فلتر.
الألوان للكروت والنصوص والموشن قرافيكس فقط.

## طبقة الخلفية

`cosmos()` = سديم يتنفّس + حلقات متمركزة + 260 نجمة بمولّد أرقام مبذور
(النجوم ثابتة بين الفريمات، والوميض وحده يتحرّك). فوقها `edgeVeil()` يمسح
النجوم من مناطق أزرار انستقرام — فينييت طبيعي، وفحص المنطقة الآمنة يعدّي نظيفاً.

## المسار

```bash
W=work                                   # مجلد الشغل
ffmpeg -i src.mov -vn -ac 1 -ar 16000 $W/a.wav

python3 pipeline/vad_cut.py   $W models  # خطة القص بالـVAD
python3 pipeline/asr.py       $W models  # تفريغ whisper-large-v3 (ONNX)
python3 pipeline/align.py     $W         # محاذاة الكلمة على منحنى الطاقة
python3 pipeline/cut_zoom.py  $W         # القص + زوم لكل مقطع
node    04_render_frames.js   $W all     # رسم الفريمات
python3 05_sfx.py             $W         # المؤثرات الصوتية
bash    06_encode.sh          $W out/ad-final.mp4
bash    06b_master.sh         $W out/ad-final.mp4 out/ad-master.mp4
```

`src.mov` (المصدر الأصلي) مو مرفوع هني — ضعه بجذر المجلد قبل إعادة البناء.

### ليش سكربتات قص وتفريغ خاصة

- **`vad_cut.py`** — المقطع مصوَّر داخل سيارة، وأرضية الضجيج عالية (‎-22dB)،
  فكشف السكتات بالعتبة رجّع صفر سكتة. Silero VAD يميّز الكلام عن ضجيج الطريق:
  13 مقطع كلام، وانشال 8.45 ثانية سكوت (16%).
- **`asr.py`** — `whisper-large-v3` بصيغة ONNX. الدقة عالية على اللهجة الخليجية،
  بس نسخة الديكودر هذي بلا مخرَجات cross-attention فما تعطي توقيت التوكن.
- **`align.py`** — لذلك التوقيت يُبنى ببرمجة ديناميكية: كل كلمة تُعطى مدّة متوقعة
  من عدد حروفها، والحدود تُختار عند هبوط الطاقة. حدود الجُمل نفسها من الـVAD
  (دقّتها أقل من 0.1 ثانية)، والتوقيت داخل الجملة تقريب قد يزيح كلمة عن مكانها قليلاً.
